# weibo-group-watcher

> 微博群聊镜像工具 —— 把微博群聊完整搬运到本地，随时随地安静地看。

一个本地运行的工具：通过微博网页版聊天接口**实时接收**指定群聊的全部消息，存入本地数据库，并通过网页面板提供安静的阅读体验（手机可添加到主屏幕，当 App 使用）。

**状态**：规划完成，开发开始前（0/11 步）

## 功能特性（规划）

- 实时接收群消息（长连接推送，断线自动重连 + 精准补漏）
- 本地永久存储 + 图片缓存（微博图片链接 3 小时过期，缓存才能长期回看）
- 网页面板：待读角标、续读定位、特别关注高亮、搜索与按人筛选
- 只读设计：绝不发送任何消息，群友无感知
- 手机适配（添加到主屏幕当 App）+ 开机自启

> 以上为规划中的功能，完成后随开发进度逐项勾选。

## 技术栈

Python 3.11 · WebSocket 长连接（Bayeux 协议） · SQLite · Flask · SSE · PWA

## 隐私说明

本仓库不含任何账号凭证与群信息：`cookies.json`（登录凭证）与 `config.local.json`（群配置）仅供本地运行使用，已被 `.gitignore` 排除。工具为只读设计，不发送、不点赞、不做任何写操作。
