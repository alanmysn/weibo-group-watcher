# weibo-group-watcher

> 微博群聊镜像工具 —— 把微博群聊完整搬运到本地，随时随地安静地看。

一个本地运行的工具：通过微博网页版聊天接口**实时接收**指定群聊的全部消息，存入本地数据库，并通过网页面板提供安静的阅读体验（手机可添加到主屏幕，当 App 使用）。

**状态**：开发中（5/11 步）

## 功能特性

- 实时接收群消息（长连接推送，断线自动重连；**只收不拉**，不干扰手机端微博角标）
- 本地永久存储 + 富字段（头像/表情/分享卡片，本地缓存可离线回看）
- 网页面板：消息流、本地图片、聊天附件下载、待读/特别双阶段角标、续读分割线、最近一次休眠提醒、最近 7 天遗漏记录与「补漏至此」、搜索与按人筛选（规划中）
- 只读设计：绝不发送任何消息，群友无感知
- 手机适配（添加到主屏幕当 App）+ 开机自启（规划中）

## 技术栈

Python 3.11 · WebSocket 长连接（Bayeux 协议） · SQLite · Flask · SSE · PWA

## 快速开始

```bash
# 1. 准备环境（首次）
uv venv .venv --python 3.12
.venv/Scripts/python.exe -m pip install websocket-client flask requests

# 2. 配置（本地隐私文件，不入库）
#    config.local.json: group_id / group_name / uid / cookie_file（见 01 文档 §探针结论）
#    cookies.json: 微博登录 Cookie（21 条，含 ALF 长效凭证）

# 3. 初始化建库
.venv/Scripts/python.exe main.py init

# 4. 启动（长连接采集 + 面板服务）
.venv/Scripts/python.exe main.py run
```

- 面板地址：<http://127.0.0.1:8765>（仅本机）；双击根目录 `打开面板.bat` 可按需启动工具并打开面板，`停止工具.bat` 只停止本工具
- 缺口管理与手动补漏：首页只提醒最近一次，`/gaps` 查看最近 7 天并按双锚点「补漏至此」（详见 03 §6.2）

## 隐私说明

本仓库不含任何账号凭证与群信息：`cookies.json`（登录凭证）与 `config.local.json`（群配置）仅供本地运行使用，已被 `.gitignore` 排除。工具为只读设计，不发送、不点赞、不做任何写操作。
